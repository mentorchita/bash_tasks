# Лабораторна робота: Основи Bash та синтаксичні особливості

Ласкаво просимо до лабораторної роботи з командного товмача Bash!
Мета цієї роботи — опанувати створення Bash-скриптів, роботу зі змінними, умовними операторами, циклами та масивами, уникаючи поширених синтаксичних помилок.

## 📁 Структура репозиторію

- `tasks/` — каталог для коду студентів (заготовки скриптів)
  - `task1_greeting.sh` — Завдання 1: Лапки та Shebang
  - `task2_check_param.sh` — Завдання 2: Перевірка аргументів ($0, $#, -z)
  - `task3_calc.sh` — Завдання 3: Арифметика та цілочисельний бар'єр
  - `task4_grade_check.sh` — Завдання 4: Числові оператори порівняння (-ge, -lt)
  - `task5_process_file.sh` — Завдання 5: Перевірка файлів [ -f ] та цикл while
  - `task6_array_demo.sh` — Завдання 6: Індексовані масиви та ${#elem}
- `tests/` — скрипти автоперевірки
- `.github/workflows/` — налаштування CI (GitHub Actions) для автоматичної перевірки при git push

## 🚀 Як виконувати роботу (Воркфлов)

1. **Склонуйте репозиторій**:
   ```bash
   git clone <URL_РЕПОЗИТОРІЮ>
   cd bash-lab-starter
   ```
2. **Перейдіть до потрібного завдання** у папці `tasks/` та допишіть рішення.
3. **Надайте права виконання** вашому скрипту:
   ```bash
   chmod +x tasks/task1_greeting.sh
   ```
4. **Запустіть перевірку локально**:
   ```bash
   ./tests/run_all_tests.sh
   ```
5. **Запушьте зміни на GitHub**:
   ```bash
   git add .
   git commit -m "Виконано завдання 1 та 2"
   git push origin main
   ```
   GitHub Actions автоперевірка виконається автоматично і покаже статус (зелена галочка / червоний хрестик).
